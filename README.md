- ✅ Steam (Supported)
- ✅ itch.io (Supported)
- ❓ Epic Games (Works occasionally)
- ❓ Microsoft Store (Works occasionally)
- ❓ Cracked (Works occasionally)
- ❌ iOS/iPadOS/Android (Not Supported)
- ❌ Switch/Xbox/Playstation (Not Supported)
